# Medical Terminology - Section Intro Script

**Video Type:** Section Introduction (Coach Mode)
**Duration:** 60-90 seconds
**Tone:** Warm, encouraging, demystifying

---

## Script

### [Acknowledge]
"Medical terminology. This is the one that scares a lot of people. You see these long, complicated words and think, 'How am I ever going to remember all of this?' I get it. It looks like a whole different language."

### [Reframe]
"But here's the secret: it IS a language. And like any language, it has rules. Medical terms aren't random — they're built from pieces. A prefix at the front, a root in the middle, a suffix at the end. Once you learn those pieces, you can decode words you've never even seen before. It's like having a cheat code."

### [Preview]
"We're going to teach you those building blocks. Prefixes like 'hyper' and 'hypo.' Root words that tell you which body part we're talking about. Suffixes that tell you what's happening — is it a condition? A procedure? A test? Plus the abbreviations you'll see constantly in charts and messages."

### [Navigate]
"Now, see this toggle at the top? You've got two modes here, and they're designed to work together. 'Lessons' is where you'll learn — reading content that explains each category with examples. 'Study Mode' — that's your flashcard practice. Flip cards, test yourself, build that memory. I'd suggest: do a lesson, then practice in Study Mode. Lesson, practice. That rhythm really works."

### [Encourage]
"Give yourself a week with this. You're going to be amazed at how quickly those intimidating words start making sense. Let's decode this together."

---

## Production Notes

- **Setting:** Professional but approachable
- **Delivery:** Address the fear directly, then reframe with excitement about the "cheat code"
- **Visual suggestion:** Show example of word breakdown (e.g., "cardio-myo-pathy")
- **UI demo:** Point to or show the toggle between Lessons and Study Mode
- **Energy:** Build enthusiasm — this can actually be fun

## Key Messages to Convey

1. Medical terminology fear is common and valid
2. It's a language with rules, not random memorization
3. Learn the pieces = decode any word
4. Two modes work together: learn, then practice
5. A week of focus = dramatic improvement
