## Video File Locations

Videos are stored in two locations:

1. **`docs/` subfolders** - Source/backup videos organized by section
2. **Supabase Storage** - Production videos served via CDN (`https://vwieorhlcapeeamvltqa.supabase.co/storage/v1/object/public/videos/`)

When updating videos, upload to Supabase Storage and keep a backup in the docs folder.

## Content Status Legend

- **Complete** - Script written, video produced, lesson implemented
- **Pending Update** - Current video exists, improved version planned
- **Pending** - Script exists, video in production
- **Planned** - Scheduled for future development
