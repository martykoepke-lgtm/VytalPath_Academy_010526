# VytalPath Academy: Curriculum Structure Recommendations

## Executive Summary

This document recommends a reorganized navigation structure that:
1. Leverages existing strong content
2. Fills critical CMAA gaps in logical learning order
3. Creates intuitive navigation for learners
4. Maps cleanly to CMAA exam domains

**Proposed Structure: 8 Navigation Sections**

### SECTION 8: Medical Terminology
**Route:** `/terminology`
**CMAA Domains:** D1 (Foundational Knowledge)
**Status:** ✅ Exists - Add abbreviations content

**Current Content (Keep):**
- Introduction to Medical Terminology (video)
- Word Building: Decoding Terms (video)
- Common Prefixes (reading)
- Common Roots (reading)
- Common Suffixes (reading)
- Flashcard Study Mode
- Module Quiz

**Add to This Section:**
- [ ] Medical Abbreviations reading — *D1 gap*
- [ ] Joint Commission "Do Not Use" Abbreviations reading — *D1 gap*
- [ ] Common Condition Terminology by Body System reading — *D1 gap*
- [ ] Abbreviation flashcard deck

**Why Moved to End:**
Terminology is a reference/study tool. Learners will return to it throughout the program. Placing it at the end:
1. Allows focused study before certification exam
2. Serves as review after learning context in earlier modules
3. Flashcards work better when learner has seen terms in context

**Learning Outcome:** Student can decode, spell, and use medical terminology correctly.
